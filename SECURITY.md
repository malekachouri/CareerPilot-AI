# Security policy

Please **do not open a public issue** for security problems. Report them privately through
GitHub: **Security → Report a vulnerability** on this repository (private security advisory).

Include what you found, how to reproduce it and the impact you expect. You will get an answer within 7 days.
Target fix times: critical 7 days, high 30 days.

Scope: this repository (API, web app, container images, CI). Vulnerabilities in third-party dependencies
should also be reported upstream.
