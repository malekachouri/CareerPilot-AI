# 05 — API Design

## Conventions
- Base path `/api/v1`; JSON; OpenAPI 3.1 generated by FastAPI → TS client generated for the web app.
- Auth: session cookie (browser) or `Authorization: Bearer <personal access token>`.
- Errors: RFC 9457 `application/problem+json` (`type`, `title`, `status`, `detail`, `errors[]`).
- Pagination: cursor-based `?limit=&cursor=` → `{items, next_cursor}`; filters as query params.
- Idempotency: `Idempotency-Key` header accepted on submissions (answers, code runs).
- Streaming: SSE (`text/event-stream`) for coach and long-running progress.
- Rate limits (Valkey token bucket) returned via `RateLimit-*` headers; stricter on auth, code runs and LLM routes.
- Role notation below: 🌐 public · 👤 learner · ✍️ contributor · 🛡 reviewer · ⚙️ admin.

| Method | Path | Role | Purpose |
|--------|------|------|---------|
| POST | `/auth/register` | 🌐 | Create account (can be disabled → invite-only) |
| POST | `/auth/login` · `/auth/logout` | 🌐/👤 | Session management |
| POST | `/auth/password/forgot` · `/auth/password/reset` | 🌐 | If SMTP configured |
| POST | `/auth/2fa/setup` · `/auth/2fa/verify` | 👤 | TOTP |
| GET/PATCH | `/me` · `/me/profile` | 👤 | Account & career profile |
| GET/POST/DELETE | `/me/tokens` | 👤 | Personal access tokens |
| GET | `/me/export` | 👤 | GDPR export (async job → download link) |
| DELETE | `/me` | 👤 | Account deletion |

## Content & Tests Hub
| Method | Path | Role | Purpose |
|--------|------|------|---------|
| GET | `/questions` | 👤 | Search/filter (q, domain, skill, difficulty, type, provenance) — answer keys excluded |
| GET | `/questions/{id}` | 👤 | Question without key |
| POST | `/questions` | ✍️ | Propose a question → review queue |
| PATCH | `/questions/{id}` | 🛡 | Edit → new version |
| POST | `/questions/{id}/report` | 👤 | Report an issue |
| GET | `/tests` · `/tests/{id}` | 🌐/👤 | Catalogue |
| POST | `/tests` | 👤 | Custom test (manual or `generator_spec`) |
| PATCH/DELETE | `/tests/{id}` | owner | Manage own test |
| POST | `/tests/{id}/attempts` | 👤 | Start attempt → returns attempt + first question(s) + `deadline_at` |
| POST | `/attempts/adaptive` | 👤 | Start adaptive session for skill(s) |
| GET | `/attempts/{id}` | owner | State (resume) |
| PUT | `/attempts/{id}/answers/{position}` | owner | Save/overwrite answer (autosave) |
| POST | `/attempts/{id}/next` | owner | Adaptive: get next question |
| POST | `/attempts/{id}/submit` | owner | Finish & grade |
| GET | `/attempts/{id}/results` | owner | Score, breakdown, keys & explanations |
| GET | `/me/attempts` | 👤 | History |
| GET | `/me/review/due` · POST `/me/review/{card}/grade` | 👤 | Spaced repetition |

## AI Coach
| POST | `/coach/sessions` | 👤 | Create session (`question_help` w/ question_id, `mock_interview` w/ persona/role, `writing`, `speaking`) |
| GET | `/coach/sessions` · `/coach/sessions/{id}` | owner | List / transcript |
| POST | `/coach/sessions/{id}/messages` | owner | Send message → SSE stream of tokens + citations |
| POST | `/coach/questions/{id}/explain` | 👤 | Explain question without revealing answer (SSE) |
| POST | `/coach/questions/{id}/options` | 👤 | Generate MCQ options for an open question |
| POST | `/coach/answers/{attempt_answer_id}/feedback` | owner | Detailed feedback after submission (SSE) |
| POST | `/coach/questions/{id}/similar` | 👤 | Generate N similar questions (labelled ai_generated) |
| POST | `/coach/sessions/{id}/end` | owner | Finish mock interview → report |
| POST | `/coach/sessions/{id}/audio` | owner | Upload voice turn → transcript → reply (+ TTS url) |
| GET | `/coach/models` | 👤 | Available local models / provider status |
