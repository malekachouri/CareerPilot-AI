# 11 — Content & Licensing Policy

## 1. Provenance labels (shown on every item)

| Label | Meaning | Example | UI badge |
|-------|---------|---------|----------|
| `official_public` | Published by the organisation itself as public practice/sample material | A company's official sample assessment page, a certification vendor's free sample questions (only if their terms allow reuse — otherwise **link only**) | "Official sample" + link |
| `community_licensed` | From a public resource whose licence permits our use, with attribution | A GitHub question bank under CC BY / MIT | "Community · CC BY 4.0 · source" |
| `ai_generated` | Generated by our agents | Similar-question generator output | "AI-generated · unverified/reviewed" |
| `user_created` | Written by a platform user | Custom test | "Created by user" |

**Never**: present any item as "the real test of Company X", copy proprietary assessments (HackerRank/Codility/SHL/
Talogy/Aon/Raven's/certification exam dumps, LinkedIn skill assessment reproductions), or claim leaked content.
Company pages contain only official public resources, publicly documented interview processes and **community-reported
topics with a source link**, clearly labelled.

## 2. Licence decision table for imports

| Licence | Store & display | Edit/adapt | Commercial use of platform | Obligations |
|---------|-----------------|-----------|----------------------------|-------------|
| CC0 / Public domain | ✅ | ✅ | ✅ | none (credit anyway) |
| MIT / Apache-2.0 / BSD | ✅ | ✅ | ✅ | keep copyright/licence notice |
| CC BY 4.0 | ✅ | ✅ | ✅ | attribution, indicate changes |
| CC BY-SA 4.0 | ✅ | ✅ (adaptations under BY-SA) | ✅ | attribution, share-alike for that content |
| CC BY-NC(-SA) | ⚠️ only if platform stays non-commercial | ✅/SA | ❌ | flagged `commercial_use_allowed=false`; hidden if operator enables commercial mode |
| CC BY-ND / BY-NC-ND | ⚠️ verbatim only, or **link only** | ❌ | ❌ for NC | default: **link only** |
| GPL/AGPL (applied to text) | ⚠️ case by case | ✅ with same licence | ✅ | reviewer decision |
| No licence / "all rights reserved" / custom restrictive | ❌ **link only** | ❌ | ❌ | — |

Rules: licence recorded at **source and item level** (with commit SHA for GitHub); the importer refuses items from
sources not `approved`; `link_only` sources produce catalogue cards that link out, without content.

## 4. Takedown & corrections

- Contact address configurable by operator, shown on the credits page.
